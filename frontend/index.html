📖 How to Use

1
Open on Windows/Mac (Device 1)

Start the server and open in Chrome/Edge: http://localhost:3001

2
Find Your Network IP Address

Windows: Press Win + R, type cmd, then type ipconfig. Look for IPv4 Address
Mac: System Preferences → Network → Advanced → TCP/IP
Example IPs: 192.168.1.100, 192.168.0.50, 10.0.0.25

3
Open SAME URL on Other Device

✅ Connect other device to same WiFi network
✅ Open browser (Chrome/Safari) and type: http://YOUR_IP:3001
✅ Example: http://192.168.1.100:3001
⚠️ Must be EXACT same URL on both devices!

4
Create & Join Room

On Device 1: Click "Create Room" → Get 6-digit code
On Device 2: Click "Join Room" → Enter the code

5
Transfer Images

Drag & drop images or click to browse. Images transfer directly over WiFi at 50-150 Mbps! 🚀

💡 Tip: Both devices must be on the same WiFi network for direct transfer to work!
