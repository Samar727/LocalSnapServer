📖 How to Use

1
Connect Both Devices to Same WiFi

Make sure both devices (Windows, Mac, iPhone, Android) are connected to the same WiFi network

2
Open Website on Both Devices

Open this website in Chrome, Safari, or any modern browser on both devices
Use the same URL shown above on both devices

3
Create Room on First Device

On the first device (sender), click "Create Room" button
You'll see a 6-digit code like: A3K7M9

4
Join Room on Second Device

On the second device (receiver), click "Join Room"
Enter the 6-digit code from first device
Wait for "Connected - Ready to transfer!" message on both devices

5
Send Images

On sender device:
• Drag & Drop images into the drop zone, OR
• Click the drop zone to browse and select images
Images will transfer instantly at 50-150 MB/s over WiFi! 🚀

6
Download on Receiver

On receiver device, images appear automatically as they arrive
Click "Download All" button to save all images as a single ZIP file
Or click individual images to view/download separately

💡 Tips:
• Both devices must be on same WiFi for direct transfer
• Files transfer peer-to-peer - never uploaded to any server
• Works between any devices: Windows ↔ iPhone, Android ↔ Mac, etc.
• For best speed, keep devices close to WiFi router
• Large images (5-10MB each) transfer in seconds!
